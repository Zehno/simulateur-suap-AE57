# Scope SUAP V1 — installation et utilisation

## Contenu
- `index.html` : application complète (interface stagiaire + formateur).
- `supabase.sql` : création de la table de synchronisation.
- `GUIDE_FR.md` : procédure pas à pas.

## Démarrage local
Ouvrir `index.html` dans un navigateur récent. Le moniteur et les commandes locales fonctionnent en démonstration. Pour piloter un autre appareil à distance, configurer Supabase puis publier le fichier sur GitHub Pages.

## Liens d'accès
Après publication :
- Stagiaire : `https://VOTRE-PSEUDO.github.io/VOTRE-DEPOT/`
- Formateur : `https://VOTRE-PSEUDO.github.io/VOTRE-DEPOT/?mode=control`

Les deux appareils saisissent le même code de session dans Réglages. L'adresse de base reste stable si tu changes de téléphone.

## Limites V1
Les tracés sont des formes d'onde synthétiques pédagogiques, pas des signaux médicaux validés. L'ECG 12 dérivations est une représentation simplifiée. Les alarmes sont visuelles dans cette version ; le navigateur peut bloquer l'audio tant qu'une interaction n'a pas été effectuée. La synchronisation dépend de la configuration Supabase et d'Internet.
