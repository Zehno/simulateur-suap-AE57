Configuration du patient

Le mode pédiatrie adapte les plages de référence affichées dans l'interface, sans validation clinique automatique.

Connexion formateur / stagiaire

La clé publique anon est destinée au navigateur. Ne place jamais de clé service_role ici. La V1 utilise une table publique de simulation : ne saisis aucune donnée nominative ou médicale réelle. Le code de session sert à rejoindre une simulation, ce n'est pas une authentification sécurisée.

Pilotage formateur — constantes

État stable : variations discrètes autour des constantes de référence.

Saisis la TAS et la TAD, puis applique-les : les valeurs sont mises à jour immédiatement sur le moniteur stagiaire.

Force la FC à 0, la SpO₂ à 0, désactive leurs variations et affiche une asystolie. La dernière tension affichée reste celle de la dernière mesure.
